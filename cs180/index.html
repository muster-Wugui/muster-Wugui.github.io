This page holds all of my CS 180 work. Every project I complete for the course gets its own write-up here — the approach, the intermediate steps, the images produced, and what did or did not work. Links go live as each project is submitted.

About the course

CS 180 (and its graduate section 280A) is about computing with visual data — images and video. It covers image processing, computer vision, and computational photography, mixing classical algorithms with modern deep learning, and it is built around hands-on projects: you implement the ideas from lecture and then apply them to photographs you take yourself. Work is done in Python with NumPy and scikit-image / OpenCV.

Topics

The ideas the projects on this page are built on.

  • Pyramid blending
  • Image warping & homographies
